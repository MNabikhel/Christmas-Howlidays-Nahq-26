# Item audit: is every item thought through?

Test 0 of `GOAL.md`, run 2026-11-16. Every item is checked on six points: it is what it says; DIY items have a full build sheet; quantities come from a calculation with at least 10% spare; it can hang or sit as shown; it fits; and its source is verified. The quantity calculations run in `build/build_plan.py`. The build stops if any supply line falls short.

## Assumptions behind the numbers

- **Brushed paint:** 12 ml per sq ft per coat.
- **Sponge-dabbed bricks:** 8 ml per sq ft.
- **Mod Podge:** 15 ml per sq ft.
- **Foam clay:** 0.45 g per cm³. This is the heavy end of the range, so we over-buy rather than run short.
- **Clay bones:** each is its template outline (31.0 sq in for the 9") x thickness x 85% for the rounded edges, less the foil core (the outline inset 1/4", at the thickness less 1/2").
- **Foam board:** the page-2 cut plan places every part of six 10" houses, trims included, on 9 boards (88% packing); the 10th is spare.
- **Pearl medium, fine, black:** the listing does not state the jar size. The paws need about 10 ml.
- **Amazon prices:** re-checked on Nov 16 with the Edmonton postal code set. Confirm them, and the per-unit delivery on international listings, at checkout.

- Scissors (3 pairs; never on wire: the wire cutter is on the DeSerres list)
